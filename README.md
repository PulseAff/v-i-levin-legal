# V. I. LEVIN — INTERNATIONAL LEGAL SOLUTIONS
> **«Ваши права — без границ.»**

Премиальная цифровая платформа международной юридической практики **V. I. LEVIN**. Объединяет экспертный SEO-сайт, Telegram-бот для многоступенчатой квалификации лидов, закрытую систему аналитики и CRM-ready панель управления обращениями доверителей.

---

## 🏛️ 1. Концепция и позиционирование
- **Философия практики:** Закрытая частная практика для нестандартных и трансграничных юридических вызовов.
- **Осознанная конфиденциальность:** На сайте намеренно отсутствуют публичные портреты юристов. Это не скрытность, а профессиональная модель безопасности и защиты частной жизни доверителей.
- **Айдентика (НЕ Louis Vuitton):** Полностью исключена монограмма переплетенных букв L и V. Разработан авторский архитектурный векторный знак:
  - **`V`** — вектор свободы движения, преодоления границ и защиты.
  - **`I`** — вертикальная ось координат, незыблемый меридиан и столп правосудия.
  - **Ромбовидный контур и орбита** — трансграничный охват и точность.

## 💻 2. Архитектура и стек технологий
- **Фреймворк:** Next.js 14 (App Router, TypeScript, React 18)
- **Стилизация:** Tailwind CSS v3 с кастомной палитрой:
  - *Obsidian Navy* (`#070A0F`, `#0B0F15`) — глубокий фон закрытой практики
  - *Restrained Gold* (`#C5A880`, `#D4AF37`) — благородные акценты, линии и CTA
  - *Ivory / Slate* (`#F1F5F9`, `#E2E8F0`) — высокий контраст и типографика
- **Типографика:** Google Fonts *Cormorant Garamond* (заголовки) + *Inter* (текст)
- **Иконки:** Lucide React
- **Бэкенд & Лидогенерация:**
  - Next.js API Routes (`/api/leads`, `/api/telegram/webhook`)
  - Standalone Polling Runner (`scripts/run-bot.js`) для мгновенного локального запуска без вебхуков
  - Локальное защищенное хранилище `data/leads.json` с поддержкой статусов (`New` → `Qualified` → `Consultation` → `Contract` → `Completed`)

## 🤖 4. Telegram-бот (@V_I_Levin_bot)
Бот реализует 7-шаговый сценарий квалификации обращения:
1. **Выбор направления:** Иммиграция США, Бизнес, Суд, Семейное право, Договоры, Другое.
2. **Юрисдикция:** США, Германия/ЕС, ОАЭ, Кипр, Грузия, Турция или произвольный ввод.
3. **Описание ситуации:** Свободный текст с предупреждением не отправлять пароли и номера карт.
4. **Срочность:** 🔴 Срочно (24ч) / 🟠 В течение недели / 🟢 Плановая консультация.
5. **Формат:** Консультация / Аудит документов / Полное сопровождение кейса.
6. **Контакты:** Имя, Telegram username, телефон/email.
7. **Фиксация:** Генерация уникального ID заявки, запись в базу и немедленный пуш юристу в Telegram.

## ⚙️ 5. Установка и запуск

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Настройка переменных окружения:
Скопируйте `.env.example` в `.env.local` и укажите ваши ключи:
```env
TELEGRAM_BOT_TOKEN=your_token_from_botfather
TELEGRAM_ADMIN_CHAT_ID=your_personal_telegram_chat_id
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME=V_I_Levin_bot
```

### 3. Запуск веб-приложения:
```bash
npm run dev
```
Сайт будет доступен по адресу: `http://localhost:3000`

### 4. Запуск Telegram-бота (Polling):
Для мгновенного тестирования бота без настройки внешнего вебхука выполните:
```bash
npm run bot:polling
```

### 5. Сборка для продакшн:
```bash
npm run build
npm run start
```
